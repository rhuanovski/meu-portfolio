# Portfólio de Rhuan Carlos

Portfólio editorial construído com Astro, TypeScript e conteúdo em Markdown.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Conteúdo

Os arquivos ficam organizados em:

- `src/content/projects`
- `src/content/articles`
- `src/content/events`
- `src/content/certificates`

Cada publicação é validada pelo schema definido em `src/content.config.ts`.

## Validação e build

```bash
npm run check
npm run build
```
